JSS 1 Maths Quiz - install on Android
1. Upload ALL files in this folder to free HTTPS hosting (e.g. app.netlify.com/drop, or GitHub Pages).
2. On the Android phone, open the https link in Chrome.
3. Tap menu (three dots) > "Install app" (or "Add to Home screen"). The app now opens full-screen like a normal app and works offline.
4. Teacher PIN default: 2026 (change in Settings).
Optional: for a real .apk, paste the https link into pwabuilder.com > Package for Android.
